# فاتورتي

فواتير وعروض أسعار عربية احترافية للمحلات والأعمال الصغيرة. يعمل كتطبيق على الآيفون (PWA)، وبدون إنترنت بعد أول فتح.

## المميزات
- **فواتير وعروض أسعار**، وتحويل عرض السعر إلى فاتورة بضغطة
- **دفتر العملاء**: يُحفظ كل عميل تلقائيًا، مع إجمالي تعاملاته والمبلغ الباقي عليه
- **قائمة المنتجات والأسعار**: إضافة الصنف للفاتورة بضغطة
- **تنبيه الفواتير المتأخرة** وإرسال **تذكير بالدفع على واتساب**
- **تقارير شهرية**: المبيعات، المحصّل، غير المدفوع، الضريبة، أفضل العملاء، رسم آخر 6 أشهر
- **7 تصاميم للفاتورة** مع ألوان الورق واللون الرئيسي
- مشاركة PDF أو نص عبر واتساب، وطباعة
- **نسخة احتياطية** واسترجاعها من ملف
- الريال العماني بثلاث خانات، وضريبة القيمة المضافة 5%
- وضع ليلي تلقائي، والخطوط مدمجة (Cairo + Tajawal)

## التثبيت على الآيفون
افتح الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

البيانات محفوظة على الجهاز فقط.
