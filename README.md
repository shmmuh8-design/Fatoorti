# فاتورتي

صانع فواتير عربي يعمل كتطبيق على الآيفون (PWA).

- إعداد أولي بخطوات: اسم النشاط، الهاتف، السجل التجاري، العملة، الشعار
- بنود، خصم، ضريبة قيمة مضافة 5%، الريال العماني بثلاث خانات
- مشاركة الفاتورة PDF أو نص عبر واتساب، وطباعة
- يعمل بدون إنترنت بعد أول فتح، والبيانات محفوظة على الجهاز

## التثبيت على الآيفون
افتح الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
